NUTRIX PWA bundle

Isi:
- index.html: aplikasi nutrisi
- manifest.webmanifest: identitas aplikasi untuk install
- sw.js: cache dasar agar shell aplikasi bisa dibuka offline setelah pertama kali
- icon.svg: ikon aplikasi

PENTING:
Agar Chrome Android menawarkan Install app, file harus di-host melalui HTTPS.
Setelah hosting:
1. Buka URL NUTRIX di Chrome pada Galaxy S10+.
2. Ketuk menu ⋮.
3. Pilih Install app (atau Install / Add to Home screen, tergantung versi Chrome).
4. Konfirmasi pemasangan.

Data nutrisi disimpan di localStorage browser pada perangkat itu. Jangan hapus data situs jika ingin mempertahankan catatan.
Bundle ini belum berupa APK native.
